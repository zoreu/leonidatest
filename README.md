## Leonida fork on Nostr git

Leonida - natively on Windows

## Requirements

Git

nodejs

nostr-git

## instalation nostr-git

```bash
npm install -g nostr-git
```

## clone project

```bash
ngit clone npub1gfkmwxw69hwql0aw79c79m5df8027qkejzqs2hw4qu8sp5an9m7ss8upwj/leonida
```

### 4. Browse on the web

```bash
ngit web npub1gfkmwxw69hwql0aw79c79m5df8027qkejzqs2hw4qu8sp5an9m7ss8upwj/leonida
```

## Uploading updated files to your profile nostr

```bash
ngit init
ngit add .
ngit push
```

## Sharing repository

Use Discord as a channel to promote the repository, given that "pure" Nostr lacks the collaborative features found on GitHub.
